# Документация протокола бенчмаркинга (Unity-only)

Этот каталог фиксирует спецификацию этапа 1 для `VirtualHome` в режиме Unity-only.
Документы являются контрактом для последующей реализации в `estimate_scripts/main.py`.

## Назначение

- Зафиксировать воспроизводимый и честный протокол сравнения моделей разных семейств.
- Формализовать входы/выходы, сценарии, стратификацию, логи и метрики.
- Исключить неоднозначность перед началом кодовой реализации.

## Карта файлов и порядок чтения

1. `01_protocol_overview.md` - цели, границы, fairness-контракт и 2 трека сравнения.
2. `02_task_stratification.md` - детерминированный отбор задач и стратификация.
3. `03_scenarios_and_conditions.md` - уровни L1-L5, условия и naming.
4. `04_io_contracts.md` - контракт `ModelAdapter`, payload шага и формат ответа.
5. `05_logging_schema.md` - схема логов (`episode/step/event`) и структура артефактов.
6. `06_metrics_absolute.md` - аналитика по сырым логам (без фиксированного KPI-набора).
7. `07_reproducibility_and_quality_gates.md` - hash-политика, quality gates, coverage.

## Короткий glossary

- `track` - режим сравнения моделей (`unified_ranking` или `family_native_diagnostic`).
- `condition_id` - уникальный идентификатор условия запуска (сценарий + профиль возмущений).
- `pair_id` - детерминированный идентификатор пары `ideal` vs `stress` для одной задачи/seed.
- `manifest_hash` - криптографический hash манифеста запуска (задачи, seeds, условия, версии).
- `absolute metric` - метрика в абсолютных единицах (`count`, `steps`, `sec`, `tokens`), без процентов/долей.
